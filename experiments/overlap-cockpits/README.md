# Overlap cockpit experiments

These experiments combine previously isolated interface ideas. They are not
alternatives to the flight console or the direct dock.

## Bridge

One finite present:

- one Home;
- one current position;
- up to three mounted sensors;
- one explicit research question;
- an on-demand contextual chart;
- one action gate accepting direct work, traversal, transparent movements, or
  complete command escape.

Instruments may pin an exact handle or follow `current`/`home`. Observations
omit their raw engine response by default and retain it as an explicit option.
Action history is bounded and reports omissions.

## Parallax

Two positions remain visible together. Each has its own sensor. The navigator
may compare, union, intersect, or subtract them through ordinary engine
operations.

## Expedition

A sustained question, transparent movements, a current position, Home, and a
bounded cargo reservoir coexist. The interface turns repeated manoeuvres into
a voyage without deciding what should be collected.

The expedition log, cargo, and attached question evidence are independently
bounded and expose omissions.

The purpose is to test emergent usefulness from overlap: finite attention,
contrast, and sustained inquiry. Simpler interfaces remain underneath every
cockpit.
