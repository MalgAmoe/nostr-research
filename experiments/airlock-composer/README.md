# Airlock composer

An opinionated composer experiment for one agent navigator.

It has three sensors:

- **Home**: an explicitly chosen safe place from which to think;
- **Questions**: a small, non-monothematic set of active or parked inquiries;
- **Weather**: expressive but evidence-linked conditions around Home.

Its **Airlock** holds at most three visible routes of at most five ordinary
controller commands. Only one step executes at a time. Results become
alternatives; Home never changes without explicit adoption.

This is not a general framework and does not use the schema composer. Routes
may be written directly or produced by any other composer.
