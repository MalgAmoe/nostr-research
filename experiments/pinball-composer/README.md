# Pinball composer

A disposable reactive composer above the neutral controller.

- **Table** is the navigator's protected safe field.
- **Curiosities** are several live things worth bumping into.
- **Momentum** is the current ball plus recent collisions.
- **Flipper** (`fire`) executes one ordinary command. There are no routes or plans.

A successful handle moves the ball automatically. It never replaces the table.
