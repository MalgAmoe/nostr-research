# Darkroom composer

A disposable contrast composer above the neutral controller.

- **Ground** is an explicitly chosen safe source.
- **Questions** hold several open lines of inquiry.
- **Negatives** retain recent paired exposures and only their mechanical contrast.
- **Developer** (`develop`) executes two ordinary, visible commands sequentially.

The Darkroom does not choose which exposure is meaningful. It keeps both so the
navigator can see what changed when the framing changed.
