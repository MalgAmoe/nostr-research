# Schema composer experiment

`@nostrarium/schema-composer` is one interpretation of the research session's
factual schemas and observations. It arranges compatible controls, projects
show responses into panels, and composes one visible command from a focused
operation contract.

It is not part of the controller and it is not **the** Nostrarium composer.
Other composers may organize the same controller responses for different
navigators, media, research styles, or systems.

The experiment performs no acquisition, execution, recommendation, chaining,
or interpretation. Every composed result is an ordinary controller command.

```js
import {
  arrangeCommand,
  arrangeControls,
  arrangeObservation,
  composeCommand,
} from '@nostrarium/schema-composer';
```
