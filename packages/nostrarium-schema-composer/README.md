# Schema composer

`@nostrarium/schema-composer` compiles a research session's factual focused
operation contract and navigator-supplied values into one visible ordinary
command. It also retains the earlier pure arrangements of compatible controls
and already-requested observations.

It is not part of the controller and does not define a research posture.
Callers may organize the same controller responses differently; the desktop
agent depends only on its factual contract validation and command compilation.

The package performs no acquisition, execution, recommendation, chaining,
or interpretation. Every composed result is an ordinary controller command.

```js
import {
  arrangeCommand,
  arrangeControls,
  arrangeObservation,
  composeCommand,
} from '@nostrarium/schema-composer';
```
